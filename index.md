## Projects

Security tooling I've built to support detection, response, and forensics.

| Project | Stack | Description |
| :--- | :--- | :--- |
| **[MemScout](https://github.com/Fad-X/MemScout)** | `Python` · `Volatility 3` | Memory-forensics automation for DFIR — runs Volatility 3 plugins, flags suspicious activity (malicious processes, code injection, network anomalies), and generates analyst-ready reports from a single command. Cross-platform (Windows / Linux / macOS). |
| **[Eye-Shaa](https://github.com/Fad-X/Eye-Shaa)** | `Python` · `VirusTotal API` | Threat-intel enrichment tool that scores IP reputation via VirusTotal — bulk-checks IOCs from a file and triages them into harmless, suspicious, malicious, or failed-lookup buckets. |
| **[ANN Phishing Detection System](https://github.com/Fad-X/Artificial-Neural-Network-Phishing-Detection-System)** | `Python` · `ML` | Artificial neural network that classifies URLs as legitimate or phishing from URL features, trained on OpenPhish and legitimate-site datasets — applied ML for email/web threat detection. |

> **Wazuh AI SOC Analyst** *(in development)* — a read-only AI analyst layer over an existing Wazuh deployment that investigates telemetry, correlates events into timelines, and produces SOC-grade findings. Private repo for now.
